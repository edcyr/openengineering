Typing answers

Answer boxes understand arithmetic, so you can type the expression you wrote on paper instead of working it out on a calculator first. Each box shows how it read your input (for example = 13.05), so you can catch a typo before you check.

What you can type
You typeIt reads
0.145*(50+40)\(0.145(50 + 40) = 13.05\)
13.05/1.2e-3\(13.05/0.0012 = 10\,875\)
(2*6+3*0)/5\(\left[2(6) + 3(0)\right]/5 = 2.4\)
-1.2\(-1.2\): a velocity to the left, when right is positive
sqrt(0.96/1.5) or √(0.96/1.5)\(\sqrt{0.64} = 0.8\)
atan(0.6*tan(50°))\(\tan^{-1}(0.6\tan 50^\circ)\), in radians unless you add °: type the angle in degrees, e.g. 35.57

Give each answer in the unit shown next to its box: newton-seconds, kilogram-meters per second, newtons, meters per second, seconds, meters, joules or degrees. Signs matter for velocities after an impact: use the positive direction the problem gives, and type the minus sign for a velocity the other way. Inside cos, sin and tan, mark degrees with °; a bare number there is read as radians.

Tip

Typing the whole expression is faster and safer than rounding at each step: 0.145*(50+40)/1.2e-3 is exact, while rounding the impulse first can drift past the 1% tolerance.
