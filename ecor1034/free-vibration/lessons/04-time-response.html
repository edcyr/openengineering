Initial Conditions and the Time Response

Every block on a given spring vibrates at the same natural frequency, but how far it swings and where it is at each instant depend on how the motion was started. This lesson uses the initial displacement and the initial velocity to find the two constants of the solution, then the amplitude and the phase angle, and from them the complete time response.

Learning objectives

  • Find \(A\) and \(B\) in \(x = A\sin\omega_n t + B\cos\omega_n t\) from the initial displacement \(x_0\) and the initial velocity \(\dot x_0\).
  • Find the amplitude \(C\) and the phase angle \(\phi\), in the correct quadrant.
  • Write the time response for a block released from rest and for a block struck at equilibrium.
  • Use the response to find the displacement, velocity or acceleration at a given time, or the time at which an event happens.

Two constants from two initial conditions

Lesson 3 found the motion of any spring–mass system:

\[ x = A\sin\omega_n t + B\cos\omega_n t \qquad \dot x = A\omega_n\cos\omega_n t - B\omega_n\sin\omega_n t \]

At \(t = 0\), \(\sin 0 = 0\) and \(\cos 0 = 1\), so the start of the motion fixes each constant directly. If the block starts at \(x = x_0\) with velocity \(\dot x = \dot x_0\):

\[ x(0) = B = x_0 \qquad\qquad \dot x(0) = A\omega_n = \dot x_0 \]

Time response from the initial conditions

\[ x = \frac{\dot x_0}{\omega_n}\sin\omega_n t + x_0\cos\omega_n t \]

The initial displacement launches a cosine; the initial velocity launches a sine.

This is the answer to the question a free vibration poses: given where the system is and how fast it moves at one instant, where is it at every later instant? Two numbers at the start are enough, and they are exactly what two integrations need.

Amplitude and phase angle

The sum of a sine and a cosine of the same frequency is a single sinusoid, \(x = C\sin(\omega_n t + \phi)\). Expanding it and matching terms gives \(A = C\cos\phi\) and \(B = C\sin\phi\): \(A\) and \(B\) are the two legs of a right triangle with hypotenuse \(C\).

Amplitude and phase angle

\[ C = \sqrt{A^2 + B^2} = \sqrt{x_0^2 + \left(\frac{\dot x_0}{\omega_n}\right)^2} \qquad \sin\phi = \frac{B}{C},\quad \cos\phi = \frac{A}{C} \]

A calculator's \(\tan^{-1}(B/A)\) returns an angle between \(-90^\circ\) and \(90^\circ\), which is right only when \(A > 0\). Check the signs: \(\phi\) lies in the quadrant where \(\cos\phi\) has the sign of \(A\) and \(\sin\phi\) the sign of \(B\). If \(A < 0\), add \(180^\circ\) to the calculator's answer.

Two starts are so common that they are worth remembering:

Two common ways to start a free vibration
StartResponseAmplitudePhase
Displaced to \(x_0\) and released from rest\(x = x_0\cos\omega_n t\)\(C = |x_0|\)\(\phi = \pm 90^\circ\)
Struck at equilibrium with velocity \(\dot x_0\)\(x = \dfrac{\dot x_0}{\omega_n}\sin\omega_n t\)\(C = \dfrac{|\dot x_0|}{\omega_n}\)\(\phi = 0\) or \(180^\circ\)

Using the response

Example 4.1 — Released from rest

A \(2\ \text{kg}\) block on a spring with \(k = 200\ \text{N/m}\) is pulled \(50\ \text{mm}\) to the right of equilibrium and released from rest. Write \(x(t)\), and find the block's largest speed and the time it takes to first reach equilibrium.

Show solution
\[ \omega_n = \sqrt{\frac{200}{2}} = 10\ \text{rad/s} \qquad x_0 = 0.05\ \text{m},\ \ \dot x_0 = 0 \quad\Rightarrow\quad x = 0.05\cos 10t\ \text{m} \] \[ v_{\max} = C\omega_n = 0.05(10) = 0.500\ \text{m/s} \]

It first reaches \(x = 0\) when \(10t = \pi/2\): \(t = 0.157\ \text{s}\), a quarter of the period \(\tau = 0.628\ \text{s}\).

Example 4.2 — Struck at equilibrium

The same block is at rest at equilibrium when a hammer blow gives it a velocity of \(0.8\ \text{m/s}\) to the right. Find the amplitude of the vibration and write \(x(t)\).

Show solution
\[ x_0 = 0,\ \ \dot x_0 = 0.8\ \text{m/s} \quad\Rightarrow\quad x = \frac{0.8}{10}\sin 10t = 0.08\sin 10t\ \text{m} \qquad C = 0.0800\ \text{m} \]

Example 4.3 — A general start

The same block is \(30\ \text{mm}\) to the left of equilibrium and moving to the right at \(0.4\ \text{m/s}\) when \(t = 0\). Find the amplitude and the phase angle, the first time the block passes through equilibrium, and its position at \(t = 0.2\ \text{s}\).

Show solution
\[ B = x_0 = -0.03\ \text{m} \qquad A = \frac{\dot x_0}{\omega_n} = \frac{0.4}{10} = 0.04\ \text{m} \qquad C = \sqrt{0.04^2 + 0.03^2} = 0.0500\ \text{m} \]

\(\cos\phi = A/C > 0\) and \(\sin\phi = B/C < 0\): \(\phi\) is in the fourth quadrant.

\[ \phi = \tan^{-1}\frac{-0.03}{0.04} = -36.9^\circ = -0.644\ \text{rad} \qquad x = 0.05\sin(10t - 0.644)\ \text{m} \]

It passes through equilibrium when \(10t - 0.644 = 0\): \(t = 0.0644\ \text{s}\). At \(t = 0.2\ \text{s}\):

\[ x = 0.05\sin(2 - 0.644) = 0.05\sin 1.356 = 0.0489\ \text{m} \]

It is near its right extreme, which it reaches at \(10t - 0.644 = \pi/2\), \(t = 0.221\ \text{s}\).

Key takeaways

  • \(x = (\dot x_0/\omega_n)\sin\omega_n t + x_0\cos\omega_n t\): \(B = x_0\) and \(A = \dot x_0/\omega_n\).
  • \(C = \sqrt{x_0^2 + (\dot x_0/\omega_n)^2}\); \(\phi\) from \(\sin\phi = B/C\), \(\cos\phi = A/C\), in the right quadrant.
  • The frequency belongs to the system; the amplitude and the phase belong to the start.
