QuantityFormulaNotes

Peak lateral force\(F_{y,\max} = \mu(F_z)\,F_z\)Reached near the peak slip angle.
Load sensitivity\(\mu(F_z) = \mu_0\left[1 - s\,\dfrac{F_z - F_{z0}}{F_{z0}}\right]\)\(\mu\) falls as load rises.

Magic Formula\(F_y = D \sin\!\big(C \arctan \Phi\big)\)
\(\Phi = B\alpha - E\,(B\alpha - \arctan B\alpha)\)		\(D\) = peak force, \(C\) = shape, \(E\) = curvature; slope at the origin \(BCD = C_\alpha\).

QuantityFormulaNotes
Slip ratio\(\kappa = \dfrac{\Omega r_e - V}{V}\)\(\kappa > 0\) driving, \(\kappa < 0\) braking, locked wheel \(\kappa = -1\).
Linear tire\(F_x \approx C_\kappa\,\kappa\)Small slip ratios only.
Peak longitudinal force\(F_{x,\max} = \mu_x F_z\)Typically at 5–15% slip, depending on the tire.
Wheel spin dynamics\(I_w\,\dot\Omega = F_x\,r_e - T_b\)Past the peak, lock-up runs away.
Stopping distance\(d = \dfrac{V^2}{2\mu g}\)Use the peak \(\mu\) for ABS, the sliding \(\mu\) for a locked wheel.

Static axle loads\(W_f = W\,\dfrac{b}{L}\)
\(W_r = W\,\dfrac{a}{L}\)		Each wheel carries half its axle's load.
Longitudinal load transfer\(\Delta F_{z,\text{long}} = \dfrac{m\,a_x\,h}{L}\)Change in each axle's load; to the front under braking.

QuantityFormulaNotes
Axle loads under braking\(\dfrac{N_f}{W} = \dfrac{b}{L} + a_{CG}\,\dfrac{h}{L}\)
\(\dfrac{N_r}{W} = \dfrac{a}{L} - a_{CG}\,\dfrac{h}{L}\)		\(a_{CG}\) in g.
Brake force split\(F_{xf} = \beta\,W a_{CG}\)
\(F_{xr} = (1-\beta)\,W a_{CG}\)		\(\beta\) = front brake bias (front share of brake force).
Ideal brake bias\(\beta_{\text{ideal}} = \dfrac{b}{L} + a_{CG}\,\dfrac{h}{L}\)At the limit \(a_{CG} = \mu\); moves rearward when grip falls.
Front lock-up\(a_{CG}^{\text{front lock}} = \dfrac{\mu\,b/L}{\beta - \mu h/L}\)The front never locks if \(\beta \le \mu h/L\).
Rear lock-up\(a_{CG}^{\text{rear lock}} = \dfrac{\mu\,a/L}{1 - \beta + \mu h/L}\)Maximum deceleration is the smaller of the two lock values.
Set-up rule\(\beta\) slightly forward of \(\beta_{\text{ideal}}\)Fronts lock first and the car stays stable.

QuantityFormulaNotes
Dynamic pressure\(q = \tfrac{1}{2}\rho V^2\)Every aerodynamic force scales with it: double the speed, four times the force.
Drag and downforce\(F_D = q\,C_D A\)
\(F_L = q\,C_L A\)		\(C_L A\) positive for downforce. Efficiency \(C_L/C_D\).
Lateral grip with downforce\(a_y = \mu\left(1 + \dfrac{F_L}{W}\right)\)In g; constant \(\mu\).
Aero radius\(R^* = \dfrac{2m}{\rho\,\mu\,C_L A}\)Above it, grip no longer limits corner speed in this model.
Corner speed with downforce\(V_{\max} = \sqrt{\dfrac{\mu g R}{1 - R/R^*}}\)Gain over no downforce: \(1/\sqrt{1 - R/R^*}\), largest in fast corners.

QuantityFormulaNotes

Center of pressure\(x_{CP} = (1-\lambda)\,L\)Distance behind the front axle.
Front axle lateral limit\(a_{y,f} = \mu\left[1 + \dfrac{F_L}{W}\,\dfrac{\lambda}{b/L}\right]\)In g; the smaller axle limit sets the car's limit and balance.
Rear axle lateral limit\(a_{y,r} = \mu\left[1 + \dfrac{F_L}{W}\,\dfrac{1-\lambda}{a/L}\right]\)\(\lambda < b/L\): more understeer at speed. \(\lambda > b/L\): more oversteer.

QuantityFormulaNotes
Power-limited drive force\(F_x = \dfrac{P}{V}\)\(P\) at the driven wheels.
Traction limit (rear-wheel drive)\(F_{x,\text{trac}} = \dfrac{\mu\,(W a/L + F_{Lr})}{1 - \mu h/L}\)Drag taken to act at CG height.

QuantityFormulaNotes
Ackermann steer angle\(\tan\delta = \dfrac{L}{R}\)
\(\delta \approx \dfrac{L}{R}\)		\(R\) to the rear-axle center; small-angle form in radians, for \(R \gg L\).
Inside and outside wheels\(\tan\delta_i = \dfrac{L}{R - t/2}\)
\(\tan\delta_o = \dfrac{L}{R + t/2}\)		Ackermann condition: \(\cot\delta_o - \cot\delta_i = t/L\).
Off-tracking\(R_{\text{front}} = \sqrt{R^2 + L^2}\)The rear axle runs inside the front.

QuantityFormulaNotes
Slip angles (kinematics)\(\alpha_f = \beta + \dfrac{a\,r}{V} - \delta\)
\(\alpha_r = \beta - \dfrac{b\,r}{V}\)		SAE signs, as in Lesson 0.2.
Axle forces, steady turn\(F_{yf} = m\,a_y\,\dfrac{b}{L}\)
\(F_{yr} = m\,a_y\,\dfrac{a}{L}\)		From \(\Sigma F_y = m a_y\) and \(\Sigma M_z = 0\).
Linear tires\(\alpha_f = -\dfrac{F_{yf}}{C_f}, \quad \alpha_r = -\dfrac{F_{yr}}{C_r}\)\(C\) per axle.
Steer angle\(\delta = \dfrac{L}{R} - \alpha_f + \alpha_r\)Right turn: \(L/R + |\alpha_f| - |\alpha_r|\).
Sideslip at the CG\(\beta = \alpha_r + \dfrac{b}{R}\)\(b/R\) at walking pace; negative (nose into the turn) at speed.

QuantityFormulaNotes
Understeer gradient\(\delta = \dfrac{L}{R} + K\,a_y\)
\(K = \dfrac{m_f}{C_f} - \dfrac{m_r}{C_r}\)		\(K > 0\) understeer, \(0\) neutral, \(< 0\) oversteer. Multiply rad/(m/s²) by \(g \times 57.3\) for deg/g.
Yaw-rate gain\(\dfrac{r}{\delta} = \dfrac{V/L}{1 + K V^2/L}\)Steady state.
Characteristic speed\(V_{\text{ch}} = \sqrt{L/K}\)Understeer: gain peaks here at half the neutral value.
Critical speed\(V_{\text{crit}} = \sqrt{L/|K|}\)Oversteer: unstable above it (\(U_{\text{crit}}\) in Lesson 1.2).
Neutral steer point\(x_{\text{NSP}} = \dfrac{C_r}{C_f + C_r}\,L\)Behind the front axle.
Static margin\(\text{SM} = \dfrac{x_{\text{NSP}} - a}{L}\)
\(K = \dfrac{m\,\text{SM}\,(C_f + C_r)}{C_f C_r}\)		So SM and \(K\) always have the same sign.
Handling diagram\(\delta - \dfrac{L}{R} = |\alpha_f| - |\alpha_r|\) at each \(a_y\)Axle that saturates first: front = limit understeer, rear = limit oversteer.

QuantityFormulaNotes
Yaw inertia\(I_z = m k^2\)
\(\text{DI} = \dfrac{k^2}{a\,b}\)		DI is typically 0.8–1.0, so \(I_z \approx \text{DI}\,m\,a\,b\).
Equations of motion\(m V(\dot\beta + r) = F_{yf} + F_{yr}\)
\(I_z\,\dot r = a F_{yf} - b F_{yr}\)		Lateral acceleration \(a_y = V(\dot\beta + r)\).
State equations\(\begin{aligned} \dot\beta &= -\dfrac{C_f + C_r}{mV}\beta + \left(\dfrac{bC_r - aC_f}{mV^2} - 1\right) r + \dfrac{C_f}{mV}\delta \\[10pt] \dot r &= \dfrac{bC_r - aC_f}{I_z}\beta - \dfrac{a^2C_f + b^2C_r}{I_z V} r + \dfrac{aC_f}{I_z}\delta \end{aligned}\)Linear tires, constant speed.
Stability derivativesYaw from sideslip: \(bC_r - aC_f\)
Yaw damping: \(-(a^2C_f + b^2C_r)/V\)
Control: \(aC_f\)		\(bC_r - aC_f = \text{SM}\cdot L\,(C_f + C_r)\).
Natural frequency\(\omega_n^2 = \dfrac{C_f C_r L^2}{m I_z V^2}\left(1 + \dfrac{K V^2}{L}\right)\)Reaches zero at the critical speed if \(K < 0\).
Damping\(2\zeta\omega_n = \dfrac{C_f + C_r}{mV} + \dfrac{a^2C_f + b^2C_r}{I_z V}\)Falls as \(1/V\); \(\zeta < 1\) means overshoot.

\(h < 2/|\lambda|\) (real \(\lambda\))
\(h < -2\,\text{Re}(\lambda)/|\lambda|^2\) (complex)		Smallest at low speed, where sideslip decays fastest.
