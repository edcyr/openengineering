Typing answers

Answer boxes understand math, so you can type an expression instead of working out every decimal first. Each box shows how it read your input (for example = 17.72), so you can catch a typo before you check.

Type only the number or expression; the unit is shown next to the box. Use \(g = 9.81\ \text{m/s}^2\), sea-level density \(\rho = 1.225\ \text{kg/m}^3\) unless a problem gives another, and the conversions \(1\ \text{lb} = 0.4536\ \text{kg}\), \(1\ \text{ft}^2 = 0.0929\ \text{m}^2\), \(1\ \text{hp} = 0.7457\ \text{kW}\). Answers are accepted within 1%, so three or four significant figures are plenty.

Tip

Typing the expression you would put in your calculator, such as sqrt(2*120*9.81/(1.225*1.8))*3.6, avoids rounding errors that pile up when you copy intermediate decimals.
